# Fiches de connaissances — produits santé

Une fiche Markdown par produit, rédigée **uniquement** à partir des documents officiels de l'assureur rangés dans `docs/`
(conditions générales, notice / tableau de garanties, IPID, exemples de remboursement, fiche argumentaire, demande
d'adhésion). Chaque fait porte sa source (document et page). Ce qui n'est dans aucun document est écrit
« Non précisé dans les documents » : ne jamais compléter de mémoire.

**Usage** : répondre aux questions d'un prospect ou d'un commercial (délai d'attente, âge, résiliation, remboursement
d'un poste, bonus, pièces à fournir…). Chercher d'abord la section « Questions fréquentes », puis la section du sujet.
Les écarts entre documents sont listés dans « Contradictions et écarts » : les signaler plutôt que trancher.

Adresse publique : `https://fabcoh.github.io/santeo-tarifs/docs/connaissances/<fichier>.md`
